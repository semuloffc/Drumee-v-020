# Drumee — прототип VST3 (Reflexed)

Базовый прототип драм-плагина: 5 слотов сэмплов (кликабельные карточки без
отдельных кнопок, со своей страницей настроек во встроенной, на всю
ширину плагина, панели редактора сэмплов), 16-шаговый секвенсор, 5 общих
макро-энкодеров на главном экране (Timing/Groove, Ratchet/Chaos) + 2
уникальных энкодера Pitch/Sound (Pitch Rand, Velocity) и интерактивная
ADSR-огибающая (Attack/Decay/Sustain/Release/Volume) на каждый сэмпл (на
его странице в панели редактора), пресеты по центру верхней панели,
пресет-кнопки Save/New в графическом виде, GUI в тёмной эстетике по
заданной палитре, главное окно 1280×720 (16:9).

## Структура

```
CMakeLists.txt              сборка через JUCE (FetchContent, тег 7.0.9)
Source/
  Parameters.h               ID и лэйаут параметров APVTS (глобальные + per-sample)
  DSP.h / DSP.cpp             сэмпл-плеер, слоты, движок секвенсора
  PresetManager.h / .cpp      сохранение/загрузка пресетов (.xml)
  PluginProcessor.h / .cpp    AudioProcessor, обработка блока, состояние
  GUI.h / .cpp                LookAndFeel, графические кнопки (IconButton),
                               энкодеры, визуализатор шагов, слоты сэмплов,
                               встроенная панель редактора сэмплов (SampleEditorPanel)
  PluginEditor.h / .cpp       компоновка главного интерфейса + переключение
                               между секвенсором и панелью редактора сэмплов
.github/workflows/build.yml  сборка VST3 на Windows/macOS + zip-архив
```

## Локальная сборка

```bash
cmake -B build
cmake --build build --config Release
```

Собранный `.vst3` появится в `build/Drumee_artefacts/Release/VST3`.

## Сборка в CI

Любой push в `main` или тег `vX.Y.Z` запускает `build.yml`: сборка на
Windows и macOS, архивация VST3 в zip и загрузка как artifact
(а на теге — публикация в Release).

## Редактор сэмплов (0.2.4: на всю ширину плагина)

Начиная с 0.2.3 у каждого сэмпла больше нет отдельного физического окна
ОС — вместо этого есть одна встроенная панель редактора сэмплов. С 0.2.4
при открытии она занимает всю ширину плагина: колонки Timing/Groove и
Ratchet/Chaos на это время скрываются (не удаляются — их состояние не
теряется), а не просто зажимают панель по бокам. Ряд карточек сэмплов
внизу экрана остаётся на месте и виден всегда.

Открыть панель можно двумя способами:
- кнопкой `Edit Samples` в правом верхнем углу — открывает панель на
  последнем выбранном сэмпле;
- кликом по карточке нужного сэмпла внизу экрана (у карточек больше нет
  отдельных кнопок — кликабельна вся карточка) — открывает панель сразу
  на нужной вкладке.

Внутри панели — 5 вкладок (по числу сэмплов, подсвечиваются цветом своей
дорожки; активная вкладка залита цветом дорожки целиком — раньше заливка
незаметно терялась из-за бага в LookAndFeel, теперь видно чётко), заголовок
сверху — "EDIT SAMPLES —" нейтрального цвета плюс имя редактируемого
сэмпла в цвете его дорожки, слот загрузки файла (клик или drag-and-drop),
компактная секция PITCH & SOUND (Pitch Rand, Velocity — цвет привязан к
сэмплу так же, как раньше: Kick/Perc — синеватый, Clap — розовый,
Snare/FX — прежний янтарный) и секция ENVELOPE (см. ниже). Кнопка со
стрелкой назад закрывает панель и возвращает секвенсор с обеими боковыми
колонками.

Редактируемый сейчас сэмпл подсвечен одновременно в двух местах: активная
вкладка в панели и соответствующая карточка внизу экрана.

## Огибающая ADSR (0.2.5)

Секция ENVELOPE на странице каждого сэмпла — компактная полоска пиковой
осциллограммы сэмпла (обновляется при каждой загрузке файла), под ней
интерактивный график Attack/Decay/Sustain/Release в цвете дорожки этого
сэмпла, выровненный по той же горизонтали, что и осциллограмма сверху —
видно, на какую часть звука приходится каждая стадия огибающей. Плюс пять
энкодеров: Attack, Decay, Sustain, Release и Volume (Decay и Volume
переехали сюда из PITCH & SOUND — идентификаторы параметров не менялись,
старые пресеты остаются совместимыми). Три точки на графике (пик Attack,
излом Decay/Sustain, конец Release) можно перетаскивать мышью прямо по
графику — так же, как энкодерами, оба способа управляют одними и теми же
параметрами APVTS. При наведении или перетаскивании рядом с точкой
всплывает подсказка с текущим значением. При срабатывании сэмпла в
секвенсоре по кривой пробегает маркер, показывающий реальную огибающую
воспроизведения.

Поскольку у драм-сэмплов нет классического "note-off", Release всегда
подгоняется под конец сэмпла: он стартует так, чтобы уложиться в
оставшееся время воспроизведения, а если сэмпл короче, чем
Attack+Decay+Release, просто начинается сразу после Decay и обрезается
концом сэмпла. Значения по умолчанию (Attack 0 мс, Sustain 0%) сохраняют
прежнее звучание "быстрый спад к тишине" из 0.2.4, пока форма огибающей
не изменена вручную.

## Верхняя панель (0.2.3)

Выбор пресета переехал в центр верхней панели. Текстовые кнопки `Save` и
`New` заменены на компактные графические иконки (дискета / новый лист)
рядом с выпадающим списком пресетов, поведение не изменилось.

## Известные ограничения прототипа

- Пресеты хранят пути к файлам сэмплов, а не сами аудиоданные — при
  переносе пресета на другой компьютер сэмплы нужно копировать отдельно.
- Синхронизация темпа берётся из хоста через `AudioPlayHead`; в
  Standalone-режиме используется 120 BPM по умолчанию.
- Ratchet/Probability/Humanize применяются глобально ко всем активным
  шагам, а не поточечно — это осознанное упрощение для прототипа.
- Код не тестировался компиляцией локально (нет сети в среде разработки):
  первую сборку в GitHub Actions стоит проверить на ошибки компилятора.
